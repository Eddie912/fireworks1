# 粒子汇聚爱心动画设计说明

## 目标

创建一个无需构建工具或第三方依赖的独立网页。页面打开后，粒子从画面各处漂移并汇聚成爱心，随后持续跳动；用户移动指针或触摸屏幕时，附近粒子产生轻微扰动，点击或轻触时触发一次扩散动画并重新汇聚。

## 交付形式

- 仅创建一个 `index.html` 文件。
- CSS 和 JavaScript 直接内嵌在 HTML 中。
- 用户双击文件即可在浏览器中运行，不需要安装依赖或启动服务。

## 视觉设计

- 页面占满整个浏览器视口，不出现滚动条。
- 背景使用从深黑蓝到玫红、紫色的径向渐变，营造夜空般的深度，但不使用装饰性光球。
- 粒子由 Canvas 2D 绘制，使用玫红、珊瑚红、粉白和少量暖金色。每个粒子包含位置、速度、目标点、尺寸、颜色和亮度。
- 初始阶段，粒子在屏幕范围内缓慢漂移并逐渐加速靠近心形轮廓与内部采样点。
- 汇聚完成后，整颗爱心进行低频、连续的双拍跳动；粒子亮度、尺寸和透明通道同步呼吸。
- 点击或触摸时，粒子从当前中心向四周扩散，短暂停顿后重新汇聚。

## 页面结构

`index.html` 内部保持三个清晰区域：

1. **HTML 结构**：一个全屏 `<canvas>`、一个用于无障碍说明的隐藏文本节点，以及一个可选的低调提示文本。
2. **CSS**：负责页面留白、背景渐变、Canvas 尺寸、提示文本样式与减少动态效果状态。
3. **JavaScript**：负责粒子采样、动画状态、交互事件、尺寸适配和渲染循环。

JavaScript 按职责拆分为以下函数：

- `createHeartPoints(width, height)`：计算爱心轮廓与内部采样点，返回标准化目标坐标。
- `createParticles(points)`：为每个目标点创建具有随机初始位置和运动参数的粒子。
- `resizeCanvas()`：匹配 CSS 尺寸与设备像素比，并重新计算爱心目标点。
- `updateParticle(particle, time)`：根据当前阶段更新粒子位置。
- `render(time)`：清空画布、绘制粒子并请求下一帧。
- `burstAt(x, y)`：应用扩散冲量，并在指定时间后恢复汇聚。

## 数据流

1. 页面加载后读取视口尺寸并初始化 Canvas。
2. 系统以参数方程采样爱心曲线，同时生成内部填充点，得到统一的目标点集合。
3. 每个粒子从屏幕随机位置出发，以缓动与噪声偏移逐步接近自己的目标点。
4. 汇聚完成后，时间参数控制跳动与亮度呼吸；粒子仍保留少量自然漂移。
5. 指针事件为附近粒子增加短时速度；点击事件触发全局扩散状态。
6. 窗口尺寸变化时重新计算目标点，并在下一动画帧平滑适配，不重新创建页面。

## 交互规则

- 鼠标移动只影响距离指针约 120 像素内的粒子，扰动强度随距离衰减。
- 触摸移动采用与鼠标一致的扰动规则。
- 点击或轻触后展示扩散与回聚，同一时间只保留一个扩散状态。
- 指针离开页面后结束局部扰动，不影响主动画循环。

## 性能与可访问性

- 粒子数量根据视口面积动态调整，桌面目标为约 700 个，移动端目标为约 420 个。
- 所有动画通过单个 `requestAnimationFrame` 循环驱动。
- Canvas 渲染尺寸乘以设备像素比，最大限制为 2，兼顾清晰度和性能。
- 当 `prefers-reduced-motion: reduce` 生效时，跳过初始漂移与扩散，直接展示轻微呼吸的静态爱心。
- Canvas 使用 `aria-hidden="true"`，同时提供屏幕阅读器可读的隐藏说明。
- 页面不依赖颜色变化传达必要信息，核心内容始终可通过文本说明获得。

## 边界处理

- 视口极小时减少粒子数量，避免拥挤和性能下降。
- 浏览器不支持 `CanvasRenderingContext2D` 时显示简洁的文本降级提示。
- 标签页进入后台时，由浏览器自然暂停 `requestAnimationFrame`，无需额外定时器。
- 快速连续点击不会创建多个循环或重复事件监听器。

## 验证与验收

- 使用桌面浏览器直接打开 `index.html`，页面无控制台错误。
- 粒子能够从随机位置汇聚成可辨识的爱心，并持续自然跳动。
- 鼠标移动和点击均产生预期扰动，动画不中断。
- 在约 375 像素宽和 1440 像素宽的视口中，爱心保持居中且不被裁切。
- 开启系统“减少动态效果”后，页面展示低动态爱心且不执行连续跳动和扩散。
- 页面不存在滚动条、空白画面或明显的帧率下降。

## 范围外内容

- 不提供后台管理、数据存储或网络请求。
- 不加入音乐、音频频谱或外部媒体资源。
- 不提供颜色、粒子数量或动画速度的设置面板。
- 不兼容需要构建工具才能运行的框架组件形式。
